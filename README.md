# 📊 FinAnalytics SPED Dashboard

Dashboard financeiro interativo para análise fiscal e financeira a partir de arquivos SPED (Simples Nacional e Regime Normal).

## 🚀 Funcionalidades
- Upload e validação de arquivos SPED Fiscal.
- DRE Gerencial automática (Faturamento, Deduções, CMV, Lucro Bruto e Líquido).
- Gráfico Waterfall interativo de composição do resultado.
- Controle de acesso por perfis (Simples Nacional, Logística e Admin).
- Validação de segurança de arquivos e relatórios exportáveis em PDF/Excel.
